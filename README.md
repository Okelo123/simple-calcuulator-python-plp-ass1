# 🧮 Simple Python Calculator

This is a beginner-friendly Python program that acts as a simple calculator. It performs basic arithmetic operations and also allows string concatenation. It's perfect for learning how to work with user input, variables, data types, and conditional statements in Python.

## 🚀 Features

- Add, subtract, multiply, or divide two numbers
- Concatenate two strings if non-numeric values are entered
- Handles invalid inputs and division by zero
- Displays the result and the data types of the inputs and output

## 🛠️ How It Works

1. Prompts the user to enter two values.
2. Asks the user to choose an operation (`+`, `-`, `*`, or `/`).
3. Detects whether the inputs are numbers or strings:
   - If numbers: performs the selected operation.
   - If strings: only allows the `+` operation (concatenation).
4. Prints the result of the operation.
5. Displays the data types of the inputs and the result.

## 📋 Example

Enter the first number: 10
Enter the second number: 5
Choose an operation (+, -, *, /): +
Result: 10 + 5 = 15.0

Data type of first input: <class 'str'>
Data type of second input: <class 'str'>
Data type of result: <class 'float'>
